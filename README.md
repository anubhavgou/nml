# Neermedha Lab website (Next.js 14, App Router)

    npm install
    npm run dev      # http://localhost:3000
    npm run build && npm start

Edit your content (products, team, news, publications, impact numbers) in `data/content.js`.
Components live in `components/`, global styles in `app/globals.css`.
Contact form is front-end only: connect it to an API route / email service in `components/Contact.js`.
